# Hero images

`landing.html` references 5 real photos for the swipeable story-reel hero.
They aren't in this folder yet — the hero currently falls back to a colored
gradient per slide until these are added. Drop the files in with these exact
names and they'll appear automatically (no code changes needed):

| File | Content |
|---|---|
| `slide-1-satyam-guitar.jpg` | Satyam sitting on the hospital bed holding his toy guitar |
| `slide-2-satyam-resting.jpg` | Satyam resting under the blue blanket, phone beside him |
| `slide-3-satyam-with-nurse.jpg` | Satyam being comforted by a nurse, holding her hand |
| `slide-4-satyam-mealtime.jpg` | Satyam having a meal with his nurse beside him |
| `slide-5-tanya-and-satyam.jpg` | Split image: his sister Tanya, and Satyam asleep in bed |

Recommended: JPG/WebP, portrait orientation close to 3:4, ideally
&lt;300KB each so the hero loads fast on mobile data.
