# Hero images

`landing.html` references 5 real photos for the swipeable story-reel hero.
Filenames are kept stable (`slide-1` … `slide-5`) so the hero can be
re-photographed without touching the code — just drop replacement files in
under the same names (any common image format; update the extension in
`landing.html`'s `background-image:url(...)` if it changes).

|---|

| `slide-2-satyam-resting.png` |
| `slide-3-satyam-with-nurse.png` |
| `slide-4-satyam-mealtime.png` |
| `slide-5-tanya-and-satyam.png` |

Note: the current set of photos was swapped in and no longer necessarily
matches each file's descriptive name (e.g. `slide-1-satyam-guitar.png` is not
literally Satyam with a guitar) — the names are just stable slots, not
captions.

Recommended: JPG/WebP/PNG, portrait orientation close to 3:4, ideally
&lt;300KB each so the hero loads fast on mobile data.
